A snapshot is OUT OF DATE when a newer bngsim release is on PyPI, or when what it measured differs from what the repository would measure now: the suite's members, a model file, a protocol, a verdict or the harness (problems/ and the code), or the engine versions the environment pins. `bench staleness` says why; a weekly workflow runs it and keeps one issue open while a suite is out of date.

Outcomes (one per correctness job):

- PASS: BNGsim agrees with every reference
- REFERENCE_FAILED: BNGsim ran and agrees with every reference that ran; another reference failed on its own (a result about that reference)
- DIFF: BNGsim disagrees with a reference that ran, whatever else failed
- UNSUPPORTED: BNGsim declines the model or protocol as unsupported, saying why
- EXCEPTION: BNGsim failed on a model a reference ran
- TIMEOUT: BNGsim ran out of time
- BAD_TEST: the model could not be prepared, or every engine failed
