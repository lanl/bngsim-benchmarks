## Timing

Absolute seconds on the timing node. *pre-sim*: the one-time cost before the timed solves, measured cold (BNGsim: network generation, code generation and load; a reference: its own code generation and load); blank for an engine started fresh for every solve, whose load is inside every solve. *solve*: the median warm solve over the timed rounds, with its bootstrap 95% confidence interval. An engine that did not run in the correctness job is not timed (its reason is under Correctness); a timing whose correctness outcome does not let it run is withheld.

How each engine is timed:

- bngsim: warm, in-process (system under test, staggered corrector, every condition)
- amici: warm, in-process (simulate_petab with forward sensitivities, every condition)
- amici_adjoint: warm, in-process (simulate_petab with adjoint sensitivities: the PEtab log-likelihood gradient; timing only)
- roadrunner: warm, in-process (plain solve of every condition: the unit of an FD gradient)
